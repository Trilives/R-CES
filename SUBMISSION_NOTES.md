# Anonymous Submission Notes

This package is prepared for double-blind review.

- No author names, affiliations, usernames, private repository URLs, or local
  machine paths are intentionally included.
- Large binary assets are omitted and documented in `DATA_AVAILABILITY.md`.
- Model outputs are preserved verbatim where they are part of the experimental
  record; a small number of baseline rationales may contain non-English tokens
  generated by the model.
- No license or citation metadata is included in the anonymous review package.
  These should be added only after de-anonymization, if the paper is accepted.

The main paper is self-contained; this supplement provides code, schemas,
annotation documentation, and compact annotation files for inspection and
reproduction.
